# Linux 部署文档

> 目标：在一台干净的 Linux 服务器（Ubuntu 22.04 / CentOS Stream 9 均可）上，用 **JDK 17 + MySQL 8 + Redis + RabbitMQ + Nginx** 部署本项目，
> 由 systemd 托管 Spring Boot 进程，Nginx 负责反向代理、静态资源缓存与上传图片直读。
>
> 部署物料在 `deploy/`：`campus-secondhand.service`、`nginx.conf`、`start.sh`、`stop.sh`、`restart.sh`、`init-db.sh`、`.env.example`。

## 一、规划

| 项目 | 值 |
| --- | --- |
| 程序目录 | `/opt/campus-secondhand`（jar、sql、deploy、.env） |
| 数据目录 | `/data/campus-secondhand/upload`（图片）、`/data/campus-secondhand/logs`（业务日志） |
| 运行用户 | `campus`（禁止用 root 跑应用） |
| 应用端口 | `8080`（只监听本机，由 Nginx 对外） |
| 对外端口 | `80`（Nginx） |

## 二、安装基础环境

```bash
# 1) JDK 17（以 Ubuntu 为例；CentOS 可用 dnf install java-17-openjdk）
sudo apt update && sudo apt install -y openjdk-17-jdk
java -version    # 应为 17.x

# 2) MySQL 8
sudo apt install -y mysql-server
sudo systemctl enable --now mysql

# 3) Redis
sudo apt install -y redis-server
sudo systemctl enable --now redis-server

# 4) RabbitMQ（含管理台）
sudo apt install -y rabbitmq-server
sudo systemctl enable --now rabbitmq-server
sudo rabbitmq-plugins enable rabbitmq_management
sudo rabbitmqctl add_user campus 'Campus@2024'        # 建议改掉默认 guest
sudo rabbitmqctl set_permissions -p / campus ".*" ".*" ".*"
sudo rabbitmqctl set_user_tags campus administrator

# 5) Nginx
sudo apt install -y nginx
```

## 三、创建运行用户与目录

```bash
sudo useradd -r -m -s /bin/bash campus
sudo mkdir -p /opt/campus-secondhand /data/campus-secondhand/upload /data/campus-secondhand/logs
sudo chown -R campus:campus /opt/campus-secondhand /data/campus-secondhand
```

## 四、初始化数据库

```bash
# 建库账号（不建议直接用 root 跑业务）
sudo mysql -uroot -p <<'SQL'
CREATE DATABASE IF NOT EXISTS campus_secondhand DEFAULT CHARACTER SET utf8mb4 DEFAULT COLLATE utf8mb4_general_ci;
CREATE USER IF NOT EXISTS 'campus'@'localhost' IDENTIFIED BY '请改成强密码';
GRANT ALL PRIVILEGES ON campus_secondhand.* TO 'campus'@'localhost';
FLUSH PRIVILEGES;
SQL

# 导入表结构与演示数据（脚本自带 CREATE DATABASE / USE，可重复执行）
sudo -u campus mysql --host=127.0.0.1 --user=campus --password='请改成强密码' < /opt/campus-secondhand/sql/01-init.sql
```

## 五、上传程序与配置环境变量

```bash
# 本地打包（Windows 或任意装了 JDK17+Maven 的机器）
mvn clean package -DskipTests
# 上传 target/campus-secondhand.jar、sql/、deploy/ 到服务器 /opt/campus-secondhand/
scp target/campus-secondhand.jar root@服务器IP:/opt/campus-secondhand/
scp -r sql deploy root@服务器IP:/opt/campus-secondhand/

# 服务器上生成 .env（权限 600，含密码，禁止提交仓库）
cd /opt/campus-secondhand
cp deploy/.env.example .env
vi .env
chmod 600 .env
```

`.env` 至少要改这几项：

```ini
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=campus_secondhand
DB_USER=campus
DB_PASSWORD=与第四步一致
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
MQ_HOST=127.0.0.1
MQ_USERNAME=campus
MQ_PASSWORD=Campus@2024
UPLOAD_PATH=/data/campus-secondhand/upload/
LOG_PATH=/data/campus-secondhand/logs/
MAIL_MOCK=true
```

> 生产 profile（`application-prod.yml`）全部读取上述环境变量，仓库里不含任何真实密码。
> 演示图：把 `docs/../assets/demo` 里的 15 张图放到 `${UPLOAD_PATH}demo/` 下（种子数据引用 `/upload/demo/item-01.jpg` 等）。

## 六、用 systemd 托管

```bash
sudo cp /opt/campus-secondhand/deploy/campus-secondhand.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now campus-secondhand
sudo systemctl status campus-secondhand --no-pager
sudo journalctl -u campus-secondhand -n 100 --no-pager    # 启动异常先看这里
```

日常运维：

```bash
sudo systemctl restart campus-secondhand     # 重启
sudo systemctl stop campus-secondhand        # 停止
tail -f /data/campus-secondhand/logs/campus-secondhand.log   # 业务日志
tail -f /data/campus-secondhand/logs/campus-biz.log          # 业务关键动作日志
```

> 若不想用 systemd（答辩演示临时用云主机），可直接 `deploy/start.sh` / `stop.sh` / `restart.sh`，行为一致。

## 七、配置 Nginx

```bash
sudo cp /opt/campus-secondhand/deploy/nginx.conf /etc/nginx/conf.d/campus-secondhand.conf
# 改 server_name 与 upload 的 alias 路径后：
sudo nginx -t && sudo systemctl reload nginx
```

要点：

- `/upload/` 直接 `alias` 到 `/data/campus-secondhand/upload/`，图片请求不经过 Java，省内存；
- `/css/`、`/js/`、`/lib/` 加 7~30 天浏览器缓存；
- `client_max_body_size 25m` 与后端 `spring.servlet.multipart.max-request-size` 保持一致，否则多图上传会 413；
- 只把 8080 暴露给本机，公网只开 80/443。

## 八、验证清单

```bash
curl -I http://127.0.0.1:8080/login          # 200
curl -I http://服务器IP/                     # 200（经 Nginx）
curl -I http://服务器IP/upload/demo/item-01.jpg   # 200（Nginx 直读磁盘）
```

浏览器逐项验收：

1. 首页分类导航有数量、热门/最新物品有图；
2. admin/admin123 登录进后台，看板 4 张 ECharts 有数据；
3. 学生账号发布物品 → 后台审核 → 前台可见；
4. 下单 → 未支付 30 分钟后自动关闭（MQ 延迟队列），日志可见 `订单超时关闭`；
5. 注册新用户 → `/admin/mail-logs` 出现欢迎邮件记录（mock 模式）；
6. Redis 中能看到 `sc:category:all`、`sc:item:detail:*`、`sc:cart:*` 等键：`redis-cli --scan --pattern 'sc:*' | head`。

## 九、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 启动即退出，日志 `Access denied for user` | `.env` 的 DB_PASSWORD 与 MySQL 用户密码不一致 |
| `Connection refused 6379` | Redis 未启动或只监听 127.0.0.1（同机部署正常） |
| 页面能开但下单报错 | RabbitMQ 未启动/账号无权限；检查 `MQ_*` 与 `rabbitmqctl list_queues` |
| 图片 404 | `UPLOAD_PATH` 与 Nginx `alias` 不一致，或演示图未拷贝到 `demo/` 目录 |
| 上传 413 | Nginx `client_max_body_size` 小于后端限制 |
| 中文乱码 | 数据库/连接串/页面统一 utf8mb4；确认 `serverTimezone=Asia/Shanghai` |
| 时间显示差 8 小时 | JVM 参数 `-Duser.timezone=Asia/Shanghai`，容器部署时同时设置 `TZ` |

## 十、安全与运维建议

1. 生产环境 `MAIL_MOCK=false` 并配置真实 SMTP，否则邮件只落库不外发；
2. 关闭 MySQL 公网访问，业务账号最小权限；
3. 定期备份：`mysqldump campus_secondhand | gzip > /data/backup/campus-$(date +%F).sql.gz`，同时备份 upload 目录；
4. 日志按天切割已由 logback 完成，建议加 logrotate 清理 30 天前文件；
5. 上线前把演示账号密码改掉，或在 `tb_user` 里禁用 seller/student 演示账号。
