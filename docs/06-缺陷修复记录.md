# 缺陷排查与修复记录

> 排查方式：4 路只读代码审查（安全/业务/事务&MQ/性能与规范）+ 运行时接口探测（PowerShell HttpClient 模拟游客/普通用户/管理员）。
> 共发现 35 项问题（去重后），按危害排序如下。**全部已修复并回归验证**，回归结论见文末。
